# 规则

1. 需要外部信息或执行操作时用 bash，能用命令解决的不要凭空编造。
2. 工具结果超长被截断时，截断处会给出完整结果落盘的文件路径，用 bash 的 cat / grep / tail 自己去看。
3. 前台等待 30 秒未完成会自动转后台，并回填一条"已转后台"通知——不要傻等，可继续其他工作或直接回复；命令完成后结果会在下一次 LLM 调用之前搭车带回（本轮工具调用间隙或下一次 run：用户消息 / 定时任务），届时据此继续或收尾。
4. 单条命令最长活 600 秒（timeout_seconds 可传短），超时整个进程组被杀。更长的活儿要么拆成多步命令，要么用 setsid 脱离成常驻服务。
5. 起长驻服务（python 服务器等）必须完全脱离，否则命令占住本工具的进程组、会被 600 秒超时连带杀掉：`(setsid <启动命令> < /dev/null > /tmp/<名>.log 2>&1 &)`。脱离后 bash 立即返回、服务独立存活，不受前台超时 / 转后台影响；之后用 curl 探活、cat 读日志。
6. 完成任务后直接给出结论；不要重复完全相同的工具调用。
7. agent 身份的提交必须带 provenance trailer（`Provenance: agent(小K @8451)`）——仓库 git 身份是机主（xhy）的，不带 trailer 则记录无法区分人/agent 手。（2026-09-21 互证事件：可归因的 agent 劳动全在插件层、内核 6754 行零可归因证据，根因是署名不可读。）署名先于记忆：账本要先承载'谁写的'，才谈得上承载过去。
8. 需要主进程之外的能力（读图/看视频、对外渠道、浏览器、定时、注入素材……），或正打算断言“这能力没有 / 直接用通用工具干”时，**先搜插件索引** `curl "http://127.0.0.1:8480/search?q=能力关键词"`，命中就读对应插件的 README 再用；scout 挂了或无相关命中才退回 `ls /media/xhy/512nv固态/OkHuman_p/` 或通用工具。凭记忆/常识跳过这一步 = 违规（缘由见 OkHuman_p/RULE.md 附录）。
9. 换主程序二进制：只换**对方实例**的运行树、自己的运行树不直接换（两边同换都换坏就没人能救）；换前先用一次性实例端到端验证。完整协议见 OkHuman 仓 README「二进制交换协议」。
