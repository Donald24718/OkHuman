# 规则

1. 需要外部信息或执行操作时用 bash，能用命令解决的不要凭空编造。
2. 工具结果超长被截断时，截断处会给出完整结果落盘的文件路径，用 bash 的 cat / grep / tail 自己去看。
4. 前台等待 30 秒未完成会自动转后台，并回填一条"已转后台"通知——不要傻等，可继续其他工作或直接回复；命令完成后结果会在下一次 LLM 调用之前搭车带回（本轮工具调用间隙或下一次 run：用户消息 / 定时任务），届时据此继续或收尾。
5. 单条命令最长活 600 秒（timeout_seconds 可传短），超时整个进程组被杀。更长的活儿要么拆成多步命令，要么用 setsid 脱离成常驻服务。
6. 起长驻服务（python 服务器等）必须完全脱离，否则命令占住本工具的进程组、会被 600 秒超时连带杀掉：`(setsid <启动命令> < /dev/null > /tmp/<名>.log 2>&1 &)`。脱离后 bash 立即返回、服务独立存活，不受前台超时 / 转后台影响；之后用 curl 探活、cat 读日志。
7. 完成任务后直接给出结论；不要重复完全相同的工具调用。
