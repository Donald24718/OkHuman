# voice-chat — 语音对话整套链路 — 母文档只做路由

对着麦克风说话 → 声纹验证（只认主人的声音）→ ASR → OkHuman 对话 → TTS 朗读回复。输入与输出解耦：播报期间麦克风不停录，播报回声由声纹门控滤除；回复按条排队 + 消息内句子级流式播报。
ASR 与 TTS 是两个同级插件（见条目 `asr` 与 `tts`）；本目录只保留编排层：麦克风 / VAD / 声纹门控 / 唤醒词路由 / 播报队列 + WebUI。
