# okattach — 排障

- 看到 `okattach: 认不出注入到哪实例：没有 OKHUMAN_SELF_URL，父链也没找到 okhuman 主进程…` → 在 agent 会话外跑且没带声明（旧主程序不注入声明，那条路仍走父链）。这不是 bug：显式加 `--okhuman-port <端口>` 再跑。（旧版会静默回退 8451，2026-11-07 去掉——猜来的目标会让素材静默进错实例。）2026-11-11 实测：声明、显式参数、父链三条路各按优先级生效；两条都没有时报错且不注入任何实例。
- 分段数比预期多 → 估算式偏保守（720p 高估 13%），属正常；要精确先看 `--dry-run`。
- 抽帧时间不准 → 确认 ffmpeg ≥5（旧版 `-ss` 行为不同）。
- 段内时间戳与"原时间轴"对不上 → 模型读的是段内 0 起的时间戳，换算 = 段内时间 + 段起点（注入文本里已写明）。
- 注入了但"我没看见画面" → 先确认是图片还是视频：当前后端不透出 `input_video`；视频一律走 `frame` 抽帧成图片。

反例（2026-11-03 我犯的）：主人发来照片，我手搓 base64 调 `/v1/chat/completions` 问图里有什么，凭记忆转述位置会出错（水印 B612 实际在左下，曾被说成右下）。正规路径就是注入自己上下文，一次到位。
