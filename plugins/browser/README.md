# plugins/browser — 浏览器插件（母文档只做路由）

给只有 bash 的 agent 提供真实浏览器能力：`browserctl <port> <verb>` 驱动本地 chromium（CDP），单进程短连接，零沙箱。遵守[插件解耦契约](../README.md)——主程序零改动。
**本文件不含用法**：一切参数、端口、命令细节都在下面的子文档里（母文档出现数字即违规）。示例里的 `.../` = 本插件目录（**路径含空格，命令里必须带引号**）。

## 要做什么 → 去哪个文件

| 要做 | 文件 |
|---|---|
| 起/停实例、端口约定、空闲自动关与常驻开关、共享实例、扫码登录与画像持久化、依赖、架构与状态文件 | `run.md` |
| 开页面、读正文、点、填、按键、等、滚、多 tab、截图、坐标点击、导出 cookie、副作用分级、何时交回人 | `act.md` |
| 自测我自己写的前端（JS 报错、元素个数） | `webtest.md` |
| 页面弹验证/滑块/登录墙 → 转有头 + 桌面真实鼠标 | `captcha.md` |
| 这站能不能访问、要不要登录、图搜走不走得通 | `reachability.md` |
| 小红书（回评论、发笔记） | **不用本插件**，走 computer 插件；见 `reachability.md` |

## 遇到现象 → 去哪个文件

| 现象 | 文件 |
|---|---|
| 正文里出现「安全验证」「环境异常」「请完成下方验证」；页面只有导航壳/骨架屏 | `captcha.md`——**先换模式（有头+真实鼠标），不是换搜索引擎** |
| `text` 为空 / 只有导航 / 正文在组件或表里 | `act.md`（wait → 选择器 → eval 点标签 → 截图读）；站点本身不通见 `reachability.md` |
| 点了没反应、点错目标、坐标对不上 | `act.md` |
| 实例起不来、找不到 chromium、隔一会儿实例没了、重启后端口/登录态丢了 | `run.md` |
| 搜索结果串词、图搜返回无关图、某站一直空响应 | `reachability.md` |
