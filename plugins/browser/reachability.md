# browser — 本机对外可达性（决定走哪条路）

（2026-11-17 复测）

- **可直取正文**：厂商官网（cambricon.com 有完整参数表；kunlunxin.com 只有介绍页、无参数）。
- **百度**：无头常弹滑块；**有头 + 自建 `--user-data-dir` 不弹验证、直接出正文**（有头配方见 `captcha.md`）。
- **必应**：可用，但 **URL percent-encode 的中文查询会串词**（"昆仑芯K200"→"昆仑山"；我自己也栽过一次——`%E8%8F%9C` 是"菜"不是"菟"，一整轮搜出来全是菜谱）→ 改英文词、或**在搜索框里输入**再回车。
- **Bing 图片搜索**（`cn.bing.com` / `www.bing.com` 的 `/images/search`）：对中文植物名与拉丁学名都返回无关图（世界地图、表情包），2026-11-17 实测三次全废——**要找参考图别走它**，直接开条目页/机构页看图。
- **小红书一律禁用本插件**（主人 2026-10-04 明令）：走 computer 插件（`xusectl`，桌面真实浏览器），也不要用页面自带的 `_webmsxyw` 签名函数 POST 站内接口——CDP+签名接口导致回复框死、评论接口空、本机 IP 被判 300012「IP存在风险」。硬规矩与事故记录见 `xhs/SKILL.md` §0 与 `xhs/references/incidents.md`。
- **不通**：维基（含 API）、r.jina.ai、搜狗、DDG、闲鱼网页版（要登录）。
- **curl 对外一律空响应——抓网页只能走浏览器。**
