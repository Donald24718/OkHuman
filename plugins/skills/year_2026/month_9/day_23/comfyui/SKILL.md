# ComfyUI 本机操作规程（母文档 = 只做路由）

本条目只覆盖 **ComfyUI 服务侧**：怎么起、挂什么节点、模型叫什么、怎么提交与取件、跨机怎么搬。**H3 出什么、提示词怎么写、生成上的坑 → 条目 `minimax-h3/`。**

## 要做什么 → 读哪份

| 要做什么 | 文件 |
|---|---|
| 起服务/停服务与必带参数、V100 加速节点与哪些加速选项无效、现存模型名、输入输出路径、API 三步提交与取件、投递前的尺寸上限、渲染前怎么让卡 | `running.md` |
| 把 ComfyUI 搬到另一台跑、跨机腾卡与产物回收 | `port_to_peer.md` |
| 成片好不好、算不算交付 | `video-aesthetic-acceptance.md` |
| 官方提示词怎么写、某种成片风格配方（依赖 Hub 工具，只当分镜结构与镜头清单） | `MiniMax-H3-Skills/`（vendored，不改写；提示词在其 `h3-prompt-writing/`） |
| 历史实测与翻车案例（FLF2V 提示词演进、四视图小说、混音、定格 MV）、照抄提交的参考脚本 | `references/历史实测与案例-全文存档.md`、`scripts/` |

## 遇到什么现象 → 读哪份

| 现象 | 文件 |
|---|---|
| 服务起不来 / 端口不对 / 起了又被打掉 / systemd 说找不到可执行 | `running.md` |
| 采样第一步就挂、内存预取报错、加速内核不支持本卡、fp8 不支持本架构 | `running.md` |
| 跑完很久才报缺字段、提交后校验失败、队列空了取不到结果、UI 的 workflow 直接提交报错 | `running.md` |
| 改过节点或管线不生效、让卡换不回、按名字打不到服务进程 | `running.md`、`port_to_peer.md` |
| 生成的不是同一个人、场景与参考音频像没接上、画面像 PPT、手和物体糊成一团、只出黑白没上色 | `minimax-h3/` |
