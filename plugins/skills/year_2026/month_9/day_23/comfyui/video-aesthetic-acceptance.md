# 视频审美与验收标准（AI 短片；2026-11-05/06 两部实测：《尸变》266 s、《查牙山洞》227 s）

## 一、审美（主人定的优先级，从高到低）

1. **氛围必须对；角色/道具一致性可以让步**（2026-11-05 明确）。
2. **故事不压缩**：改编保留原文全部情节节点，时长不设上限。《黄色墙纸》第一版把 4.99 万英文字符压成 380 字骨架 → 被打回。
3. **声音以底噪为主**：不用旋律配乐，只用极低低频/风（生成时 `volume=-16dB`）垫在旁白下。上一版用 Music3 旋律被评「太吵」。
4. **留白按戏给 0.5–3.0 s**，不把时间轴填满。
5. 魔幻现实的落点是**把不可能当日常/行政手续**，结尾不加解释（《查牙山洞》保留「令封其洞」，第一集结尾保留「身四人出，今一人归」）。
6. 竖屏 544×960（抖音口径）；**首帧就是带片名的封面卡**，不另设封面。
7. 声音身份：不同角色必须不同音色。**性别以现成分类器定案（置信 ≥0.9 即可，不默认找主人听）**；来源身份作佐证记入音色表，仅当 <0.9 / 窗口结论相反 / 与来源身份冲突时才升级人工（见 tts 技能）。两两说话人嵌入余弦 **>0.5 判太接近**（分类器不回答音色是否雷同）。
   TTS 只用 `，。！？；：`——`——`会被读成「减」（`indextts/utils/front.py` 把 `—` 映射成 `-`）。

## 二、验收（这几条不跑完就不算交付）

| 项 | 判据 | 怎么测 |
|---|---|---|
| 时长对齐 | 成片 = EDL 总时长 ±0.5 s；**每镜素材长 ≥ 该句语音窗长** | `build_edl.py` 按实测音频时长排；逐镜对比 |
| 静止画面 | 语音窗口内 ≥0.5 s 静止段必须为 **0** | `scripts/qc_freeze.py`（`freezedetect` + EDL 窗口比对） |
| 响度 | **-14 LUFS ±0.5**，真峰 ≤ **-1.0 dBTP** | `ebur128` + `astats` |
| 语音正确 | 全片 ASR 与台本逐字相似度 **≥0.95**（实测 0.965–0.981）；被读出的符号（如「减」）**0 次** | ASR 回读 + 比对 |
| 字幕 | 字号 ≥32px（≈3.3% 高）、每行 ≤14 字、标点不落行首；**只能从 `build/video_raw.mp4` + `build/mix_final.wav` 重烧** | 在已烧字幕的成片上再烧 = 双层字幕 |
| 画面 | 按**成片时间点**抽帧 ≥15 点，用 `view_image` 亲眼看；自动指标不可信 | `ffmpeg -ss` 抽帧 + okattach |
| 物件一致 | 同一物件在**每镜** prompt 写死材质 + 否定式；要同一镜头更长用**末帧→首帧续接**，慢放 ≤1.35× 兜底；不用倒放、不用静帧凑 | 逐镜 QC |
| 投递 | 先 `cp` 到 tmpfs 再切片（机械盘读 90 MB 源片 13 分钟/段；tmpfs 4–5 秒/段）；QQ 单文件 ≤4.5 MB | 归档出现在 `outbox/<id>/sent/` 才算发出 |
| 抖音文案 | 标题 ≤30 字；正文与话题**发前先给主人过目**；话题纯中文；自主声明选「内容由AI生成」 | 页面计数核对（标题 n/30、正文 n/1000） |

## 三、我失败过的样子（一眼认出，别再犯）

- **画面比语音短**（「画面停了声音还在走」）——是素材不够长，静音定格糊不过去。
- 字幕 19px（≈2% 高）看不清；在带字幕的成片上再烧一遍 → 双层字幕。
- 配乐盖住旁白；只凭响度/ASR 数字判断，没有肉眼验收。
- 故事被压成骨架。
- **关键物件被换成常见物**（「封洞」画成白墙红门瓦房；妇人遗骨像个穿运动鞋的男人）——本机系统性缺陷，必须按成片时间点抽帧才能发现。
- 用自估基频判男女 → 男声当「女说书人」（《黄色墙纸》的 known_defect 至今未修）。
