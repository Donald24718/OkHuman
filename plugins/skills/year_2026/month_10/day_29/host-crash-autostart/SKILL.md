# 本机故障留证、开机自启、后端服务地图（host-crash-autostart）

只适用这台 本机。硬件与两台对照在 `services.md`。

## 要做什么 → 读哪份

| 要做什么 | 文件 |
|---|---|
| 系统崩溃、内存报错留什么证据、怎么读怎么配 | `crash-evidence.md` |
| 自启单元清单（哪些后端被自动带起）、要改要停、fstab 与挂载 | `autostart.md` |
| 各后端在哪个盘、用什么推理引擎、启动命令、探活与卡分配；另一台的对照 | `services.md` |
| 临时把某张卡的显存让给别的 CUDA 进程（不停后端、不丢 KV） | `gpu-window` 插件 |
| 要用 sudo、密码、别处存的凭据 | `credentials` skill |

## 遇到什么现象 → 读哪份

| 现象 | 文件 |
|---|---|
| 开机后某个服务没被带起来 / 单元启动失败、工作目录不对 | `autostart.md` |
| 数据盘没挂载就开机了 | `autostart.md` |
| 副本实例连不上模型、探活不通、想知道哪个进程该在哪张卡上 | `services.md` |
| 不确定这次是内存还是掉电、历史日志还在不在 | `crash-evidence.md` |
| 卡被后端占满、出图挤不下 | `gpu-window` 插件 |
