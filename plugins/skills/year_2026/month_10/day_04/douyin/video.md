## 7. 发视频（2026-10-05 起连投 6 条沉淀；坐标只作参考，**每轮按当次截图重新定位**）

1. **入口**：创作首页右侧「发布视频」卡片（直接访问 `content/upload` 会被弹回首页）。
   点前**必须 `windowraise <0xID>`**——别的窗（微信/朋友圈）盖在中间时，卡片 hover 会亮但点击不跳转。
   `--target` 要 `wmctrl -l` 里的**完整标题或 0xID**，只给前缀解析不到。
2. **选文件最稳的写法**：点「上传视频」→ GTK 对话框 `key ctrl+l` → 剪贴板粘**绝对路径** → `key Return`。
   别在文件列表里找行（行号随文件数变）。素材先拷到 `~/视频/`。
3. 上传中会弹「获取您的位置吗？」→ 点「阻止」。**上传期间不碰那个标签页**（不开任何弹窗、不按 `ctrl+w`）——
   标签一消失上传全丢。**草稿不存视频**：重进上传页只保留标题/正文/话题，视频必须重传。
4. **标题上限 30 字**（图文是 20 字）；超了**静默截断**，填完看 `n/30` 计数器。
5. **正文必须走剪贴板**：`xusectl type --paste` 实际仍逐字符 keysym，**长中文段落会整段吞字**。
   `printf '%s' "$TXT" | xclip -selection clipboard` → 点正文框 → `key ctrl+v`。
   核对全文的判据：**本地文件去尾换行的字符数 == 页面 `n/1000`**。加话题会让正文框内滚动、字数计数下移，别以为内容丢了。
6. **话题最多 5 个**（超了顶部弹提示、多余的**静默不生效**）。做法：`key End` → `key space`（`type` 会吞前导空格，空格要单独打）
   → `xusectl type "#纯中文词"` → `key Return`（不需要等联想下拉）。
   **混合 ASCII 打不进去**（`#AI视频` 只剩 `#`）→ 只用纯中文词。
   真话题的判据 = 正文里出现**浅蓝底 chip**；自动扫 `b−r>12 且 b>200` 会漏（底色偏灰蓝），放大看最稳；第 5 个 chip 会跨行显示，肉眼看像没成。
7. **「官方活动」卡片是陷阱**：点上去＝往正文插一个活动标签并把卡片置「已添加」。不确定活动规则就别点。
   撤销：`End` + `BackSpace`——**chip 一次删一个单元**，连发会把前面的话题一起删掉，删完必须截图核对。
8. **自主声明**：点单选**行文字**（不是圆圈），行距 ≈40–50px。选中判据＝该列（x≈583–590）出现连续暗段 ≥10；
   「确定」＝某行连续暗像素跨度 >60px 取中心（先试鼠标；**别在单选组里用 Tab**，Tab 会挪到别的选项、Return 就选错了）。
   最终判据：弹窗关闭后该行文字变成「内容由AI生成」（不是仍显示「请选择自主声明」）。
9. **封面**：视频首帧本身就是带标题的封面卡时，不传自定义封面、不理会「横/竖双封面缺失」提示，直接发布。
   要自定义见 §7a。之后会弹「设置横封面获得更多流量」→「暂不设置」（横封面自动从竖封面生成）。
   **「审核中」时改不了封面**（列表里「编辑作品」是灰的），过审后可以改但**每个作品最多 5 次**——能发布前设好就在发布前设。
10. **发布**：表单页会因点击/粘贴而滚动，跨步骤复用旧坐标必错。每步前重新 `shot`；
    要把目标行移到屏幕中部用 `xusectl scroll <x> <y> --dy N`（`--dx/--dy` 是必需参数，位置参数写法报错）；误开的下拉 `key Escape` 关。
11. **成功判据**：`content/manage` 列表顶部**滞后**（刷新两次仍显示旧条目），**计数基线也不可信**
    （实测上一集记 18、本次发完显示 20，而列表里本集只有一条）。
    用这两条之一：创作首页 `creator-micro/home` 的「最新作品」卡片（标题+封面正确、播放 0＝进审核队列），
    或列表顶部出现新条目 +「审核中」+ 时长角标。
12. **GUI 长流程中途屏幕会锁**（空闲 2–3 分钟）：`shot` 会直接报「屏幕已锁」，期间按键全喂进密码框。
    每步前 `shot` 探锁，锁了 `xusectl wake <密码>`（密码见 computer 插件 README 备忘）。

### 7a. 过审后补/改封面（2026-10-26 实测成功）

1. 列表 `content/manage` → 该作品行右侧「编辑作品」**旁边的下拉箭头 ▾**。
   点「编辑作品」文字本身会跳**作品数据详情页**（`work-detail/<id>`），不是编辑页。
2. 编辑页 URL `content/post/video?mid=<id>&enter_from=edit_item`。别动「作品描述」框（里面是已发布的标题+话题）。
3. 「设置封面」下有 **横封面4:3 / 竖封面3:4 两张** → 点要改的那张缩略图 → 「设置竖封面」弹窗
   → 右下黑底「上传封面」→ GTK 选择器 `ctrl+l` 粘绝对路径 + `Return`
   → 画布与右侧预览都变成你的图、「完成」才变黑 → 点「完成」。
4. **必须重开该缩略图核对**：点完「完成」后编辑页缩略图可能仍是视频帧（实测第一次没生效）；
   重传一次，直到缩略图 + 右侧手机预览都显示你的图。
5. 滚到底「提交修改」→ 回列表，该作品显示 **「修改审核中」**，该行暂时收起「编辑作品」入口。
   列表缩略图仍显示旧帧是缓存，不代表失败。
