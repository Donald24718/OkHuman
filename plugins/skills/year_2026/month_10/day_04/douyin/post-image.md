## 2. 发图文（已跑通）

1. 入口：创作端首页「发布图文」→ 上传页 URL 带 `default-tab=3`。
2. 传图走 **GTK 文件选择器**（三个坑，见 computer README §6）：素材先拷到
   `~/图片/<临时目录>/` → 侧栏「图片」→ 双击目录 → **Ctrl+A** → 打开；传完删临时目录。
   别跟 Ctrl+L 的自动补全弹层缠斗（它会吃 Enter）。
3. 标题/正文：点击字段 → `(setsid xclip -selection clipboard -i 文件 &)` → `key ctrl+v`。
   正文里打 `#` 会弹话题联想，按 Escape 关掉。
4. **自主声明**：「自主声明」→ 选 **内容由AI生成** → 确定。不设也能发，但该设。
5. 浏览器弹**定位授权** → 点「阻止」。
6. **成功判定**：跳到 `/creator-micro/content/manage`，**顶部出现新条目 +「已发布」+
   封面右下角"N张"角标**。别在详情页打转；回列表用地址栏粘贴（`xusectl type` 吞连字符）。


## 图文的硬上限（2026-10-04 实测有效）

最多 **35 张**；推荐 **3:4（1080×1440）**，单张 ≤50MB，宽高比不建议超 1:2。标题 **20 字**、正文 **1000 字**。
