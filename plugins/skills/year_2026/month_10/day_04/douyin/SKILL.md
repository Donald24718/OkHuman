# 抖音操作经验（douyin）— 母文档只做路由

按任务读对应子模块，别整篇读；新经验归入对应子模块，不新开平行 skill。

## 要做什么 → 读哪份

| 要做什么 | 文件 |
|---|---|
| **发之前先读**：登录态与禁用手段、要不要发、对外边界 | `before-posting.md` |
| 发图文作品（数量、比例、大小、标题正文上限） | `post-image.md` |
| 回评论；怎么知道哪些是新评论；回复口径 | `reply.md` |
| 发视频（上传、话题、自主声明、封面、成功判据）、过审后改封面 | `video.md` |
| 已禁用的旧路线（browser/CDP）当时的技术结论与事故记录 | `references/incidents.md` |

## 遇到什么现象 → 读哪份

| 现象 | 文件 |
|---|---|
| 卡进验证 iframe、重来要重新扫码、新设备指纹被拒 | `references/incidents.md` |
| 填好的草稿重加载就没了、上传控件选不到文件 | `references/incidents.md` |
| 找不到「哪些评论是新的」、创作者中心看不到当天的 | `reply.md` |
| 话题不是浅蓝 chip、正文中文被吞、自主声明没变成「内容由AI生成」 | `video.md` |
| 发出去了但作品列表里找不到、计数不涨 | `video.md` |
