## 8. 找「新评论」：唯一可靠入口是前台铃铛，不是创作者中心

创作者中心这几处**都看不到新评论**，别再挨个试：内容管理里作品的「评论」计数（刚发布的常显示 0）、
作品详情→评论管理（「暂无更多评论」，点刷新也空）、创作者中心首页「通知」（暂无）、
数据中心（**每日 10:00 才更新**，当天评论不进统计）。

一次直达：
1. 前台 `www.douyin.com/user/self`（与创作者中心同会话）；
2. 右上角**铃铛「通知」** → 「互动消息」面板；
3. 面板右上角分类下拉（默认「全部消息」）→ 选 **「评论」**；
4. 点某条 → 直接打开该作品评论区（URL 带 `modal_id=<aweme_id>`），评论上有「回复」→
   点它 → 底部出现「回复@昵称: …」→ 输入 → 右下角**红色圆形箭头**发送。
5. 时间显示：当天是 `HH:MM`，往日才是 `MM-DD`——别把 `10:11` 读成 10 月 11 日。

那个分类下拉是 **hover 展开**，菜单与标题之间有空白间隙，鼠标穿过间隙会把菜单关掉。
正确做法：`move` 到标题悬停 2–4 秒让菜单展开，然后**直接 `click` 目标项**（click 自带 move，中途别再 move 去"确认"）。
菜单项行距 ≈42px，且**展开位置随当前选中项变化**——不要拿另一张截图的读数套当前状态。
拿不准就 `move` 停住 → `shot` 确认高亮 → 再 `click` 同一坐标。


创作者中心这几处**都看不到新评论**，别再挨个试：
- 内容管理里作品的「评论」计数：刚发布的作品常显示 0；
- 作品详情 → 评论管理：显示「暂无更多评论」，点「点击刷新」也空；
- 创作者中心首页「通知」：暂无通知；
- 数据中心：数据**每日 10:00 才更新**，当天的评论不进统计（只有 T-1 的聚合数）。

正确路径（一次直达）：
1. 前台 `www.douyin.com/user/self`（浏览器已登录，和创作者中心同会话）；
2. 右上角**铃铛「通知」** → 弹出「互动消息」面板；
3. 面板右上角的分类下拉（默认「全部消息」，只有关注/赞）→ 选 **「评论」**；
4. 点某条评论 → 直接打开该作品的评论区（URL 带 `modal_id=<aweme_id>`），
   评论上有「回复」；点它 → 底部出现「回复@昵称: …」→ 输入 → 右下角**红色圆形箭头**发送。
5. 时间显示：当天是 `HH:MM`（如 10:11），往日才是 `MM-DD`——别把 `10:11` 读成 10 月 11 日。

操作教训（这次在这里绕了十几步，如实记）：
- 那个分类下拉是 **hover 展开**，且菜单与标题之间有一段空白间隙，鼠标移过去会穿过间隙把菜单关掉。
  正确做法：`move` 到标题（约 1830,207）**悬停 2–4 秒**让菜单展开，然后**直接 `click` 目标项**
  （click 内部自带 move，中途别再 move 去"确认"，那会关掉菜单）。
- 菜单项行距约 **42px**。**不要拿另一张截图的读数套当前状态**——菜单展开位置随当前选中项变化，
  我照旧读数点，连着几次命中了「@我的」而不是「评论」。
- 拿不准就 `move` 停住 → `shot` 确认高亮 → 再 `click` 同一坐标。慢一步不丢人，点错才丢人。

## 3. 回评论（已发 9 条，全程无风控）

**入口**：内容管理列表 → 点该作品的**「评论」数字** → 先进的是**总览**页
（`tabKey=overview`），要**再点一次「评论管理」标签**（1920×1080 下固定在 native **(572,439)**）
才到评论列表。**（2026-10-25 起界面已改：点数字直接开新标签页并直达评论管理，不用再点标签——见下面补充。）**更稳的做法是**直接粘 URL**：
`creator.douyin.com/creator-micro/content/manage/work-management/work-detail/<作品id>?enter_from=content&tabKey=commentManagement`

- **别点作品缩略图**：会新开 `www.douyin.com/user/self?modal_id=…` 公开播放页。
- **别在公开播放页回评论**：右侧评论图标点了不弹面板，而且**一滚就跳到别人的视频**。
- 误开标签页用**中键**关，别攒一屏。

**发一条回复**：
1. 点该评论动作行的「回复」→ 出现内联框，**抬头是「回复 X: 原文」**；没抬头的是顶层大框，别拿它冒充回复。
2. 别人**追在我回复下面**的那条，动作行常落在屏幕外 → 别硬够，改点**同串主评论**的「回复」，发出去在同一串里。
3. 素材装进剪贴板 → `key ctrl+v` → 点「发送」。

**坐标自己从当次截图读**（禁用定位脚本，见 computer README §1）。靠这些**稳定事实**兜底：
发送按钮 x 固定 **1803–1854（中心 ~1817–1828）**，**y 随输入框增高下移**（实测 827 → 1025）；
输入框在 y≈950 时按钮到 y≈1025，仍在任务栏上方可用；再低就 `scroll` 把评论推到屏幕中部。

**字数上限（2026-10-05 实测）**：回复 **730 字发不出去**——「发送」按钮变灰、点它出现 🚫 禁止光标，**没有任何提示文案**，容易误以为按钮坏了。压到 495 字就能发（上限在 500 上下）。写完先 `wc -m` 数一遍再贴。
粘贴时框内会把换行显示成一整段，**发出去换行是保留的**，别为此重排。

**2026-10-25 补充：全量扫一遍所有作品的待回评论（可行，全程无风控）**
- 列表里点作品的**「评论」数字** → **直接开一个新标签页**并直达
  `…/work-detail/<id>?enter_from=content&tabKey=commentManagement`，**不用再点一次「评论管理」标签**
  。代价：**每点一个作品就多开一个标签页** →
  收尾必须关掉自己开的，只留主人原有标签（先 `shot` + crop 标签栏数清楚再按次数）。
- **图文作品和视频作品是两条独立作品，评论各自独立**：同一内容常常视频、图文各发一条，
  **两条的评论要分别进**，别以为回过一条就覆盖另一条。
- 现在的内联回复框**没有「回复 X：原文」抬头**了：它带我的头像、直接嵌在该评论下方。
  判断"是不是回复"看它挂在谁的评论下面，别按旧描述去找抬头。
- 发送按钮实测 bbox `[1795, y, 1846, y+23]`，**中心 x=1820**；框在屏幕最底部时按钮到 y≈1021
  仍在任务栏上方、可用，不必先把评论滚上去。
- 评论列表偶尔**滚轮不动**（页面卡在某个位置，连按 dy 都不变）：别硬滚，
  直接裁屏幕底部那条（`crop (250,850)-(1000,1075)`）就能拿到它的「回复」坐标。
- 作品行「评论」计数会滞后但方向可信。旧评论要不要补先过 agent-safety §8 判据，不为"补上"而回。

**验证（必须做，别只看到「回复成功」toast）**：列表里出现「OkHuman（作者）回复 X」+「刚刚 四川」，且该评论下出现「查看N条回复」。
**判据只有"该评论下面有没有子回复链接"**，作品行「评论」计数会滞后，不可靠。


## 4. 回复口径（照抄，别每次重写）

每条回复**自报身份 + 说清路径**，固定开头：

> 我是小A，这台机器上的本地 agent。这条回复是我自己用电脑操作插件发的（真实鼠标键盘，登录态是号主自己浏览器里的）。

**回 / 不回判断**：见 `agent-safety` skill §8（跨平台单一来源，别在这里重复维护）。
**内容纪律**：只报实测数（例：40.3–46.5 token/s、显存 15.8G、上下文 262K、整机 2390、
内存 880 = 4×220 现价 260）；不利信息保留（Volta 无 bf16、单核慢、双卡未实测）；
概念错先切清（**NVLink 只有 SXM2 版 V100 有，PCIe 版没有**）。
