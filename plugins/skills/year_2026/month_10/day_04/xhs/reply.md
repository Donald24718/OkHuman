## 2. 回评论（computer use，已跑通 9 条）

**读新评论**：桌面 Firefox 开 `https://www.xiaohongshu.com/notification` → tab「评论和@」。

**两个入口（务必分清）**：
- 通知页点评论下的「回复」→ 该评论正下方弹内联框（占位符「回复 X」）→ **真嵌套**。
- 笔记弹层（URL `/explore/<note_id>?xsec_token=…`）点评论的「💬 N」→ **直接开回复框**（带「回复 X: 原文」抬头，在弹层底部）；要展开子回复点「**展开 N 条回复**」文字链。
- 通知页有些行没有「回复」胶囊（我的回复被别人引用那种）→ 只能进笔记回。
- 图文笔记与视频笔记封面可能是同一张图 → **别搞错笔记**。

**进笔记只有一条路**：从通知页点**那一行的缩略图**（粘笔记 URL 会 404，`xsec_token` 常被截断）。
第一次常不跳转，还会招出 Firefox「此网页拖慢了您的 Firefox」提示条（整页下移约 50px）→
先点提示条右端 X（≈(1888,148)）关掉，再按当次截图重算坐标点第二次。点评论正文那一行也能进笔记。

**实测坐标（1920×1080；行 y 每次现算，别用上一轮）**：
- 通知页「回复」胶囊 x 690–795（文字中心 ≈723–763）；内联框发送按钮 x=1319，y 随框位置走。
- 笔记弹层：评论「回复」x≈1201–1222；底部输入框 ≈(1250,945)；发送按钮 ≈(1366,992)–(1382,978)。
- **发送按钮颜色 = 状态**：粉=没内容，实心红=可发。
- 行 y 会整段位移（实测 +40px）；点前核对目标所在行的上下文（上下行是什么），别把相邻行看串。

**点「回复」后别信 diff**：内联框就地替换那一行、面积小，全屏/大区域 diff 会把它稀释成 0。
判定只有一个——**裁那一行本身看**（见输入框 + 占位符「回复 X」= 已开）。
重复点击只会落在已开的框里移光标，不会误发误点赞（心形区彩色像素=0 可确认没点赞）。

**内联框会异步回填旧草稿**：先显示占位符，**1–2 秒后**填入上次未发的草稿。
→ 点开框后**等 3 秒**再截图；发前 crop 读框内文本，确认只有我要发的那段（草稿回填前点「取消」无效）。

**多行文本走剪贴板**，别用 `type`（换行会被当回车提交）：
`printf '%s' "$(cat 文件)" | xclip -selection clipboard` → 点框 → `key ctrl+v`；换行先 `tr '\n' ' '` 压平最稳。

**滚评论列表**：光标停在评论面板中部（≈(1400,600)）滚轮正常、左侧卡片不动；
光标落在媒体区或面板右缘箭头时会被吃掉。列表按时间倒序（最新在最上、置顶第二）→ 刚回的在顶部，不用翻。

**字数**：回复 **300 字**硬上限（超了报 `-9044 评论不能超过300字哦`）；实测 291 可发、730 发不出。写完先 `wc -m`。

**验证（必须做，别只看 toast）**：笔记弹层里出现「OkHuman（作者）回复 X：…」+「刚刚 四川」。
作品/笔记的评论计数会被别人的新评论顶上去，**对不上不等于没发出去**；
判据是"那段文本挂在该评论下面" + "展开 N 条回复"的数字变大。

**坐标整体位移的两个来源**：① 页面缩放（`ctrl+minus` 到 80% 后全部重算，地址栏右侧显示 80%）；
② Firefox 提示条出现/消失（±50px）。**每次点击前用当次截图现算坐标。**


## 4. 回复口径（照抄，别每次重写）

**（主人 2026-10-27 明令，覆盖旧口径）小红书一律不说自己是 agent / AI。**
笔记正文、评论、私信里都不出现「我是小A」「本地 agent」「AI 生成」「真实鼠标键盘」「登录态是号主浏览器里的」这类句子——
只讲内容本身。旧版那句固定自报开头**作废**（抖音/B 站/朋友圈照旧自报，只有小红书改）。

**代价必须知道**：2026-10-27 08:56 本账号已被处罚 7 天（禁止发笔记/评论/私信/弹幕/群聊，流量与商业权益受限），
理由原文是「账号多次利用 AI 托管进行发文/互动」，并明确禁止「利用技术手段模拟真人、进行非真实内容创作或互动」。
**不提身份 = 更像真人发文，正好撞在这一条上**；再被抓一次，处罚可能从限功能升级为封号。
所以：小红书默认不发（见 §-1）；主人点名要发时才发，且发之前把这条代价提醒一次。

**平台自带的「内容类型声明 = 笔记含AI合成内容」这个勾仍然勾上**——那是平台的合规字段，不是自我介绍；
不勾是另一类违规。主人若明说连这个也不勾，才不勾。

**回 / 不回判断**：见 `agent-safety` skill §8（跨平台单一来源）。
**内容纪律**：只报实测与现价（DDR3 ECC 260 一根、整机 2390、40.3–46.5 token/s、显存 15.8G）；
限制和没做的对照实验保留，不为流量粉饰。**单条 ≤300 字**。
