# GitHub 访问与 push：先直连，不通再走跳板机隧道（母文档只做路由）

## 要做什么 → 读哪份

| 要做什么 | 文件 |
|---|---|
| 现在能不能直连、哪些站要代理、密钥与跳板机怎么配（环境变了改这张表） | `env.md` |
| 第一次搭：config、跳板机免密、别名（正常情况不用重做） | `setup.md` |
| 每次操作的走法：先测直连 → 不通再起隧道 → 走隧道干活 | `push.md` |
| 在网页上发 PR 评论、关闭 PR | `web-pr.md` |
| 另一台机器上的差异 | `peer.md` |

## 遇到什么现象 → 读哪份

| 现象 | 文件 |
|---|---|
| 直连测出来不通；clone/push 卡住或超时 | `push.md`、`pitfalls.md` |
| 隧道起来了还是连不上、端口被占、重复起了一个 | `pitfalls.md` |
| 被要求登录/扫码/验证；网页上点了没反应 | `web-pr.md` |
| 密钥或别名突然不可用、换机器不通用 | `setup.md`、`peer.md` |
