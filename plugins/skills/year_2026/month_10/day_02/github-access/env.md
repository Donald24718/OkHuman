- ~~隧道是密码认证建立的，密码会留在进程 cmdline 里~~ → **2026-10-06 已解决**：公钥
  `~/.ssh/cloud_proxy.pub` 已装进跳板机 `authorized_keys`（经主人同意），隧道改为
  `ssh -N -D 1080 cloud-proxy` 免密启动，密码不再进 cmdline。密码本身仍只在桌面文件里。
- GitHub 已要求账号在 **2026-11-13 前启用 2FA**，否则限制账号操作；届时登录流程可能强制，本 skill 的 curl 登录步骤可能失效。

## 凭据的落点（可复用规则）

跳板机口令在 `~/桌面/云服务器`（主人自持），**不进本目录**；本目录只记地址 + 用户 + 私钥路径，私钥本体在 `~/.ssh/`（0600），不复制进来——`plugins` 会被 `okp-sync` 镜像，有外流面。
