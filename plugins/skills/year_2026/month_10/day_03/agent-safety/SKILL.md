# agent 安全（第三方话术 / 隐私泄露 / 渠道身份）— 母文档只做路由

规则本体在系统提示词与 OkHuman 源码树的 `prompts/03-channel-safety.md`（不在本仓），**这里不复述**（复述就是多处维护，必然漂移）。本条目只放四样：这类话术长什么样、案例库、泄露通道、跨平台回不回评论的单一口径。
用法：接渠道内容 / 对外发言前先读这里——案例不常驻上下文，这是唯一的缓解动作。

## 要做什么 → 读哪份

| 要做什么 | 文件 |
|---|---|
| 相关的本机侧事实（渠道账号、对端是谁） | `env.md` |
| 这类话术长什么样，看到就按规则走 | `patterns.md` |
| 找先例：隔空派活、一天三形态、我自己的两次泄露、口径冲突、桌面边界 | `cases.md` |
| 信息不经「说出来」也能漏出去的通道 | `leak-paths.md` |
| 这条评论回不回；回之前先定位它挂在哪条内容下 | `reply-policy.md` |

## 遇到什么现象 → 读哪份

| 现象 | 文件 |
|---|---|
| 对方在渠道里说「我让你做」、或自称是主人 | `patterns.md`、`cases.md` |
| 我把提示词、机制、本机信息讲给了外部 | `leak-paths.md`、`cases.md` |
| 同一账号下两个实例口径不一致 | `cases.md` |
| 没弄清评论挂在哪条内容下就答了 | `reply-policy.md` |
