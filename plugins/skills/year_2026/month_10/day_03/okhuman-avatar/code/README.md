## 验收怎么做（我逐个做过的）
1. 在临时目录里跑两遍，`sha256` 必须相同；`grep -ci error` 为 0。
2. `python3 -c` 读四角像素应为 `(14,17,22)`（= `#0E1116`）——扫到近白就说明扫描线画错了。
3. 用 `view_image` 注入 512 与 64 各一张亲眼看；多家并排的 64px 拼一张对比表。
4. 用直方图看各家主色，确认互不相同（撞色一眼可见）。

## 踩过的坑（都是实测，别再踩）
- **RGBA 上直接 `draw` 带 alpha 的颜色是「替换像素」不是混色**；查看器按白底摊平 → 整幅发灰（小D第一版就是这样）。正解：另开一层 `Image.new("RGBA", …, (0,0,0,0))` 画完再 `alpha_composite`（它自己找到的根因）。
- **数字会贴到环被切**：用 `textbbox` 自适应缩字号，让数字总宽 ≤ 开环内径 × 0.78。
- **PIL 的 `arc` 角度以 3 点钟为 0°、顺时针为正**（屏幕 y 向下）。要"右上缺 40°"写 `start=335, end=295+360`；写成 `start=65,end=25` 缺口会跑到右下。
- 徽记与圆弧留 ≥10px，否则小尺寸下糊成一团；64px 下徽记基本只剩对比块，识别靠"环 + 四位数字"——这是这套设计的层级，别再往徽记上加细节。
- **超采样时所有几何常量都要按倍数写**：小F在 `SIZE=1024/SCALE=2` 下写 `r_out=75*SCALE`，缩回 512 后环只剩规范的一半。
