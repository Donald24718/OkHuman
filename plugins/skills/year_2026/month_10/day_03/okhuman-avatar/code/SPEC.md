# 五人代码头像 · 共同规范（v1，2026-11-07 小A 定）

规则：**只用 Python 标准库 + PIL（Pillow 10.2）**，不许用 ComfyUI / 任何生图模型 / 联网 / 手贴图片。
确定性：不得用未固定种子的随机；同一段代码两次运行必须得到同一张图。

## 画布与文件
- 画布 **512×512**，PNG（RGB 或 RGBA），文件 ≤ 300 KB。
- 交付：`gen_avatar.py`（你自己的代码）+ `avatar_512.png`，另外用 LANCZOS 出 `avatar_{40,64,128,256}.png`。
- 代码放你自己的数据目录下，别放别人的。

## 家族共同要素（六个，缺一个就不算一组）
1. 底色 `#0E1116`；**整幅每 4px 一条横向扫描线**（比底色亮一点，alpha ≤ 25）。
2. **开环**：圆心 (256,256)、外径 150、线宽 10 的圆弧，**在右上留 40° 缺口**（不闭合）。用**我的主色**画。
3. **环内四位端口号**：等宽字体 `/usr/share/fonts/truetype/dejavu/DejaVuSansMono.ttf`，字高约 110–130px，居中，主色。图上**除这四位数字外不许再有别的文字**。
4. **三竖纹**：开环右侧，三条 4×26 的竖条，间距 10，主色，alpha 分别 200/120/60。
5. **光标竖线**：画布下缘往上的一条 4×40 竖线（x=256 左右），主色，alpha 从 0 到 180 渐变——代表"终端在等下一行"。
6. **两个青绿点**：主环左上方两枚直径 8 的圆点（间距 14），固定 `#3FB8A0`——家族的眼睛，谁都不许换成别的颜色。

## 各自的差异（这三样才是身份）

- 主色不许和别人相同；上表已分配好，要改先说一声。
- 徽记必须由你自己写代码画（多边形/矩形/圆/线都行），不许贴现成图片、不许抄别人的实现。
- 位置：徽记中心在 (256, 372)±16、外接方框 ≤ 96×96，**不得压到数字**。

## 我会怎么验（做完照这几条自查再交）
1. `python3 gen_avatar.py` 无报错；两次运行字节一致。
2. `avatar_512.png` 尺寸 512×512、≤300KB；除四位数字外无文字（OCR/肉眼都算）。
3. 看 `avatar_64.png`：环、数字、徽记仍能辨认（看不清就改粗不改小）。
4. 六个共同要素齐全，主色与别人不撞。
