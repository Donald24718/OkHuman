# credentials — 账户与密码的保管与取用（母文档只做路由）

## 要做什么 → 读哪份

| 要做什么 | 文件 |
|---|---|
| 这台机器上有哪些账户（明文清单） | `accounts.md` |
| vault 的布局、怎么建、怎么加/改/删条目 | `vault.md` |
| 我怎么取用（只取字段、不打印整份）、ssh 的取用方式 | `use.md` |
| 存放铁律、按重要性的分级、反模式与它们的扩散路径、对外怎么提 | `rules.md` |
| 本机环境事实、副本落在哪些地方 | `env.md` |
| 另一台机器上的差异 | `peer.md` |

## 遇到什么现象 → 读哪份

| 现象 | 文件 |
|---|---|
| 想把密码抄进技能目录 / 想打印整份出来 | `rules.md` |
| 取不到值、报没权限、sudo 要口令 | `use.md` |
| vault 不存在、结构不对、忘了主人在哪建的 | `vault.md`、`env.md` |
| 同一份凭据在别处出现了一份（副本扩散） | `env.md` |
| 在另一台机器上要取用 | `peer.md` |
