# LESSONS（scout）

1. **字段类型不许猜**：`meta.json` 的 `keywords` 可能是字符串或数组。未知字段一律容错解析，
   且解析失败必须可见（`meta_problems`）——静默跳过 = 少一条没人知道。
2. **派生数据必须自带自检面**：索引这类可再生的东西要有 `/doctor`（当场重扫与内存对照）。
   "少一条"只有靠对照才能发现，靠记忆不能。
3. **方向由对照集决定，不由感觉决定**：语义项、分词去单字、权重高低三个假设都被实测打回；
   真正的杠杆是字段里有没有那个词（`keywords`）。没有查询对照集的结论不算结论。
4. **动手前先看清现场**：仓库在不在、既有配置内容是什么、命令跑在哪个仓。
5. **先给最小可验证形态再加**：本轮从「增量+持久化+压实+稳定 id+redirect+定主+倒排」削到
   「纯关键词 + keywords 字段」，每一步削减都有实测或明确否决。
