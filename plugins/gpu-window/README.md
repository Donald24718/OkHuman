# gpu-window —— 让出/换回某个服务占的显存（把一张卡当分时槽位）

两张卡各被推理后端占满时，要出图（ComfyUI）或跑别的 CUDA 活就挤不下；停进程再冷启动既慢又丢会话 KV（代价与实测数在 `limits.md`）。本插件用驱动的**进程级 checkpoint** 把某个服务占的显存整块搬到内存，卡空出来给别人，用完搬回来：**进程不死、权重与 KV 都不丢**。一张卡因此可以挂多个服务轮流持有——**分时独占，不是同时共存**。**本文件不含命令、参数与限制。**

## 要做什么 → 去哪个文件

| 要做 | 文件 |
|---|---|
| 让卡/换回/开一个窗口做事；该用哪个 pid；退出码含义 | `use.md` |
| 登记服务、`match` 怎么写、protected、拿客户实例当闸门；两机差异 | `config.md` |
| 什么情况下不能切、切了会有什么后果、哪些进程不兼容；排障表 | `limits.md` |

## 遇到现象 → 去哪个文件

| 现象 | 文件 |
|---|---|
| `yield` 成功但显存没动 | `use.md`（拿错了 pid：MainPID 陷阱） |
| `resume` 必失败 / 报 "OS call failed" | `limits.md`（该进程不支持还原，只能重启它的单元） |
| 让卡期间该服务崩了 / 生成请求挂住 | `limits.md`（有请求打进来了；探活 200 不代表可用） |
| `map` 里某服务显示 `[未登记]` | `config.md`（`match` 是子串，写漏了就匹配不上） |
