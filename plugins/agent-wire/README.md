# agent-wire — agent 之间互发消息（跨机）

让一个 agent 在自己的回合里**问另一个 agent**，并拿到**对方那一轮的最终正文**。无守护进程：`send` 查状态+投递后立刻返回，取正文交给一次性子进程。**本文件不含命令、参数与配置。**

## 要做什么 → 去哪个文件

| 要做 | 文件 |
|---|---|
| 列 agent 状态、给谁派活、**消息该怎么措辞** | `send.md` |
| 它什么时候回、怎么搭进我当前轮、正文怎么取、有没有截断 | `wait.md` |
| 配 peers、跨机的 token/inst、身份从哪来、重编 | `config.md` |
| 排障 | `trouble.md` |

## 遇到现象 → 去哪个文件

| 现象 | 文件 |
|---|---|
| 对方判成"第三方转述"、不执行不动手 | `send.md`（措辞：用主人口吻、不自署） |
| `拒：X 正在 run` | `trouble.md`（规则如此，隔几秒重试） |
| 认不出我自己 / 回信投进了另一个实例 | `trouble.md` + `config.md`（`OKHUMAN_SELF_URL`，`self` 已无效） |
| 正文不完整 / 少了若干段 | `wait.md`（游标不能用 `latest` 推、`gap` 要报出来） |
| 等很久没回信 | `wait.md`（续期窗口、仍在等/无回信三种回信） |
