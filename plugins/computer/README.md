# computer use 插件（xusectl）

给 agent 装"手"：整屏截图（ffmpeg x11grab）+ X11 鼠标键盘事件（xdotool/XTest）。视觉走现有 okattach（截图注入上下文），**内核零改动**（只用 bash + /inject）。
**本文件不含用法**：命令、参数、坐标规则、坑都在下面的文件里。

## 要做什么 → 去哪个文件

| 要做 | 文件 |
|---|---|
| 找命令与参数、两台机器的桌面差异、起停与等待、基本循环 | `usage.md` |
| 读坐标、点得准、管窗口和标签页 | `click.md` |
| 往应用里输入文本（含长文本、带符号的串、微信这类难缠的输入框） | `typing.md` |
| 屏幕锁了、屏保唤不回 | `screen-lock.md` |
| 桌面像卡住：右键没菜单、按键进不了应用 | `xstuck.md` |
| 事故原文与逐条复盘（**归档**，以现行文件为准） | `LESSONS.md`、`PLAN.md` |

## 遇到现象 → 去哪个文件

| 现象 | 文件 |
|---|---|
| 点击落在别处 / 点了没反应 / 坐标对不上 / 误关标签 | `click.md` |
| `shot` 报「屏幕已锁」；按键像没生效 | `screen-lock.md`（先 wake） |
| 粘进去是空的 / 输入丢字符、顺序错位、连字符消失 | `typing.md` |
| 右键无菜单、键盘有输入却进不了应用 | `xstuck.md` |
| `sleep` 等太久；两条命令抢鼠标；`diff` 说没变但确实变了 | `usage.md` |
