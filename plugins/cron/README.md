# cron/ — 定时任务插件（okhuman-cron）

给 OkHuman 实例排定时任务的独立常驻进程：到点把任务 prompt 投进该实例的消息队列，**只管发、不等那一轮跑完**；每实例独立存储，与主程序零代码耦合。**本文件不含端点、参数与端口。**

## 要做什么 → 去哪个文件

| 要做 | 文件 |
|---|---|
| 起停、重编、改 config、看数据落哪 | `run.md` |
| 加/删/暂停/立即跑一个任务，查任务与运行记录 | `api.md` |
| 它到底等不等结果、错过周期怎么补、能不能拿到回复 | `link.md` |
| 排障 | `trouble.md` |

## 遇到现象 → 去哪个文件

| 现象 | 文件 |
|---|---|
| 到点没跑 | `trouble.md`（看 next_run_at / paused） |
| 入队失败、或"跑了但插件记成失败" | `trouble.md` + `link.md`（只管发的语义） |
| 想要定时任务的回复内容 | `link.md`（插件拿不到 reply，去实例界面看） |
| 改了 config / 挪了目录不生效 | `run.md`（data_dir 启动时算定） |
